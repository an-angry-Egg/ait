# AIT-模块：轨迹圈选与批量选中

本模块负责「用户不动按键、只用鼠标绕一圈」时的全部行为：追踪轨迹、画出拖尾、判定这是不是一个圈、圈住了哪些组件、把它们一次性选中。

它与语音无关。语音只提供语义（改什么），本模块只提供指代（改哪一个）。

---

## 1. 职责

| 编号 | 职责 | 产出 |
|---|---|---|
| R1 | 持续追踪鼠标坐标，维护滑动窗口轨迹 | `S.points` |
| R2 | 把轨迹画成带衰减的拖尾，并在锁定后定格淡出 | canvas 绘制 |
| R3 | 纯几何判定「这段轨迹是不是有意绕的一圈」 | `detectLoop()` |
| R4 | 圈内元素采样、语义单元提升、父子去重、上限截断 | `pickGroup()` |
| R5 | 把候选组交给浮窗与高亮框，成为后续草稿与提交的作用域 | `S.selected` |

## 2. 不做

- 不监听 `mousedown` / `mouseup` / `click`。鼠标全程不按键，因而不存在「画圈误触按钮」这一类风险，也不需要任何 click 抑制。
- 不做实时逐字上屏。
- 不判断「用户想改什么」，那是语音与自然语言解析的事。
- 不对未唤醒的页面采集鼠标。只在聆听态与草稿态生效。

## 3. 数据契约

### 3.1 状态

```js
S.points      // [{ x, y, t }]  滑动窗口轨迹，按 t 升序
S.lastMoveAt  // number         最近一次采样的时间戳
S.loopInfo    // { n, turn, w, h, gapR }  上一次判定的中间量，仅供排障
S.lockedBox   // { x1,y1,x2,y2,w,h }      锁定瞬间的包围盒
S.frozen      // [点]           锁定瞬间的轨迹快照，用于淡出
S.frozenAt    // number
S.cooldownUntil // number       冷却截止时间
S.candidates  // [Cand]         命中池，按分数降序
S.selected    // [Cand]         选中组，按视觉顺序（上→下、左→右）
S.target      // Cand           组内主目标（分数最高）
```

### 3.2 候选对象

```js
Cand = {
  el:    Element,   // 已提升到语义单元的元素
  votes: number,    // 圈内采样票数（提升时同单元合并累加）
  area:  number,    // 元素面积，用于面积过滤与排序
  score: number     // 语义匹配分，见 §5.5
}
```

### 3.3 不变的约定

- `S.selected[0]` 不保证是 `S.target`，两者顺序口径不同：选中组按视觉顺序呈现编号，主目标按语义分数。浮窗与上下文包都以 `S.target` 作为「主指代」，以 `S.selected` 作为「作用域」。
- `S.selected` 为空时，所有下游一律回退到 `[S.target]`，绝不出现空作用域。

## 4. 参数表

### 4.1 轨迹窗口 `LOOP`

| 参数 | 值 | 作用 |
|---|---|---|
| `windowMs` | 6000 | 只保留最近 6 秒的轨迹 |
| `maxPoints` | 420 | 点数上限，约 6 秒 × 70Hz |
| `minPoints` | 24 | 少于这么多点不判定，排除手抖 |

时间窗不能卡太紧。一圈画得慢一些（自动化逐点驱动、或用户手慢），起点就会被裁掉，只剩后半段弧——实测 40 点慢速整圈只留 34 点，角度从 350° 掉到 303°，判定直接失败。跨笔隔离由 `resetAfterMs`（停笔即清空）负责，时间窗只做兜底，可以给得宽松。

### 4.2 成圈阈值

| 参数 | 值 | 作用 |
|---|---|---|
| `minAngle` | 330° | 累计绕行角度下限，满 360° 少一点留容差 |
| `minSize` | 48px | 包围盒宽高下限 |
| `closeRatio` | 0.35 | 首尾距离 ÷ 对角线，排除「画大弧线」 |
| `holdMs` | 400 | 绕满后须停住多久才认定完成 |
| `resetAfterMs` | 700 | 停住超过此时长则收笔、清空轨迹 |
| `cooldownMs` | 2000 | 触发后冷却，防止同一动作连触 |
| `tickMs` | 90 | 判定定时器周期 |

### 4.3 呈现参数

| 参数 | 值 | 作用 |
|---|---|---|
| `TRAIL.lifeMs` | 760 | 单个轨迹点的可见寿命 |
| `TRAIL.fadeOutMs` | 620 | 锁定后定格轨迹的淡出时长 |
| `MAX_CANDS` | 16 | 命中池上限，须大于 `MAX_SELECT`，否则圈满一屏选不满 |
| `MAX_SELECT` | 6 | 一次最多选中 6 个 |
| `OUTGROW` | 1.5 | 元素面积超过圈面积的倍数即视为「比圈还大」 |
| `COVER_MIN` | 0.5 | 元素至少一半面积落在圈里才算「被圈住」 |
| `LIFT_PAD` | 10 | 判断「整块在圈里」的容差 |

## 5. 处理链

```
mousemove ──► 采集 ──► 拖尾绘制
                 │
                 ▼
           定时器 tick（90ms）
                 │
                 ▼
         ┌───────────────┐
         │ 成圈判定       │ 角度 / 尺寸 / 闭合 三者同时满足
         └───────┬───────┘
                 │ 成立
                 ▼
         ┌───────────────┐
         │ 停顿确认       │ held ≥ 400ms
         └───────┬───────┘
                 │ 确认
                 ▼
         ┌───────────────┐
         │ 锁定 lockLoop  │ 冻结轨迹、起冷却、清窗口
         └───────┬───────┘
                 ▼
         ┌───────────────┐
         │ 命中与提升     │ 8×8 采样 → liftToUnit
         └───────┬───────┘
                 ▼
         ┌───────────────┐
         │ 批量归并       │ 面积过滤 → 父子去重 → 截断 → 视觉排序
         └───────┬───────┘
                 ▼
            浮窗 + 高亮框
```

### 5.1 采集

`onMove(e)` 在 document 捕获阶段执行：

1. 不在聆听/草稿态，直接丢弃。**在浮窗上方照常采集**——见下。
2. 追加 `{ x: clientX, y: clientY, t: now }`，更新 `lastMoveAt`。
3. 按 `windowMs` 从头部淘汰旧点，按 `maxPoints` 截断。
4. 触发拖尾绘制。

坐标一律用 `clientX/clientY`，与 canvas 的 `position: fixed` 坐标系一致，不做 DPR 换算——canvas 的位图尺寸等于视口尺寸，1:1 映射。

**采集不因浮窗中断**。浮窗固定在右上角，经常正好压在目标上。若在浮窗范围内丢点，弧线会断一段，角度就不够成圈——实测圈「编辑资料」时 40 个点被吃掉 6 个，角度从 350° 掉到 303°，判定失败。聆听/草稿态下的鼠标移动本来就只有一个意图：构图。

代价是圈整片压在浮窗上时也会成圈，所以 §5.3 锁定前有一道浮窗守卫。

### 5.2 成圈判定

`detectLoop(points)` 依次检查三条，任一不满足即返回 `null`：

1. **点数** `n ≥ minPoints`
2. **尺寸** 包围盒宽、高均 `≥ minSize`
3. **角度** 以包围盒中心为原点、按半轴归一化成圆后累计**有符号**极角，取绝对值 `≥ minAngle`

角度算法不采用「相邻弦的方向角差」：轨迹扁长时长轴端附近切向角变化最快，采样稀疏会单步跳过 180°，被归一化吃掉角度（实测整圈只算到 264°）。归一化极角对同一轨迹单调，采样再稀也不跳变；带符号累加还能让往返移动自行抵消。

4. **闭合** 首尾距离 ÷ 对角线 `≤ closeRatio`

判定过程写入 `S.loopInfo`，并通过 `<html data-ait-state>` 暴露，供自动化与排障读取。

### 5.3 停顿确认

鼠标绕满一圈后往往还在动。若此时就锁定，用户「再微调一下」的意图会被打断。因此加一道停顿闸门：

- 定时器每 `tickMs` 检查一次，`held = now - lastMoveAt`
- `held ≥ holdMs` 才调 `lockLoop()`
- 若判定未成立且 `held > resetAfterMs`，说明这一笔已废，清空轨迹，避免与下一笔混在一起

`lockLoop()` 内另有一道**浮窗守卫**：圈的包围盒与浮窗矩形重叠超过 80% 时作废并提示。因为采集已不避浮窗，整圈压在浮窗上是「在跟浮窗打交道」，不该去选它下面的页面元素。阈值定在 0.8 是留足余量——实测被浮窗压住的按钮，其圈只重叠 53%。

### 5.4 命中与提升

采样：在包围盒内取 8×8 网格共 64 个点，每点用 `elementsFromPoint` 取栈，跳过不可选元素后**只计第一个**，避免父链把所有祖先都刷一遍票。

`selectable(el)` 排除：浮窗与 canvas 自身、`HTML/BODY/SCRIPT/STYLE` 等、尺寸小于 6px、面积超过视口 85%。

提升 `liftToUnit(el, box)`：命中最深的节点常是 `span`、`td`，直接选中会得到一堆格子。沿父链向上走，只要祖先仍**整体落在圈内（含 `LIFT_PAD` 容差）**且可选，就把结果换成该祖先，最多 8 跳。圈住两行表格得到的是两行，不是一堆单元格。

### 5.5 批量归并

`pickGroup(points, box)` 六步：

1. **合并**：提升后落在同一元素的票数累加，一个元素只留一条，同时算出 `cover`（元素面积中落在圈内的比例）。
2. **覆盖率过滤**：`cover < COVER_MIN` 的丢弃。这一条必须用几何比例而不是票数：8×8 网格在包围盒边缘会外溢一列，紧邻的元素也能拿到 8 票（实测圈「编辑资料」时，「修改密码」拿到 8 票却只被覆盖 1%）。
3. **面积过滤**：`area > 圈面积 × OUTGROW` 的丢弃——它比圈还大，不是「被圈住的东西」。
4. **容器让位**：外层容器若内含覆盖率明显更高（+0.2）的子元素，则容器出局。采样点常落在两个控件的间隙上，`elementsFromPoint` 会把外层布局容器（如 `.profile-actions`）带进池子；它面积大，在第 5 步的降序去重里先占位，会把真正的按钮挤掉。实测后果是改动刷在容器上、按钮自身背景一盖，看起来像完全没生效。
5. **父子去重**：按面积**降序**遍历，先让容器占位；与已保留项存在包含关系的一律跳过。降序保证留下的是「最大的那个整体」。
6. **截断与排序**：最多 `MAX_SELECT` 个，最后按视觉顺序（`top` 升序，同 `top` 按 `left` 升序）重排，使浮窗编号与页面所见一致。

兜底：若没有元素通过过滤，退回 `cover` 最高的一个（不是票数最高——票数会被外溢的网格列污染），总比空手好。

### 5.6 语义打分

`scoreOf(cand, text)` 用于在组内挑出主目标，权重与产品定稿一致：

| 维度 | 分值 |
|---|---|
| 文本匹配（元素可见文本） | 60 |
| `aria-label` 匹配 | 45 |
| 类型提示（说「按钮」时命中 `BUTTON/A` 等） | 20 |
| 票数（上限 15） | 15 |
| 带 `data-ait` | 5 |
| 面积惩罚（越小越高，上限 10） | 10 |

## 6. 呈现

### 6.1 拖尾

- 逐段按时间衰减，透明度 `0.08 + 0.80·k²`，线宽 `0.8 + 3.2·k`，`k` 为剩余寿命比。平方衰减让尾部化得快、头部保持实。
- 笔尖画双层光点（半径 9 的淡环 + 半径 4.2 的实心点），让人看得见笔在哪。
- 用 `requestAnimationFrame` 自驱动，鼠标停住时也继续衰减，直到所有点过期再清画布。

### 6.2 锁定后的定格

锁定瞬间把轨迹快照进 `S.frozen`，按 `fadeOutMs` 淡出，同时画一个虚线包围盒（900ms 后撤除）。目的是给一个「我认了这一圈」的即时反馈，避免轨迹突然消失。

### 6.3 高亮框

按 `S.selected` 逐个画框，主目标用实线加光晕，其余虚线。框上标签只给主目标，内容为「元素名 · 文件:行:列」，优先放框下方，下方不够放上方，都不够才放进框内。

## 8. 边界情形

| 情形 | 期望行为 |
|---|---|
| 轨迹从浮窗上经过 | **照常采集**。浮窗常压在目标上，丢点会让弧线断裂、角度不足 |
| 整圈压在浮窗上 | 重叠 >80% 时作废并提示，不去选它下面的元素 |
| 圈里没有任何可选元素 | 提示「圈里没有可选元素」，不进入草稿态 |
| 圈擦到相邻元素 | 覆盖率 <50% 的不计入，只选主体 |
| 采样点落在两个控件的间隙 | 外层布局容器让位，选中的是具体控件而不是容器 |
| 圈住整页某一大容器 | 面积过滤丢弃，退回覆盖率最高项 |
| 圈住 20 个格子 | 父级提升合并为若干行，最多取 6 个 |
| 连续绕两圈 | 首圈锁定后进入冷却，第二次绕圈被忽略 |
| 草稿态再绕一圈 | 允许，覆盖当前选中组；已输入的草稿保留 |
| 页面滚动后 | 高亮框与 `lockedBox` 用视口坐标，重绘时按最新 `getBoundingClientRect` 计算 |

## 9. 验收

| 编号 | 用例 | 判据 |
|---|---|---|
| A1 | 聆听态移动鼠标画弧 | canvas 出现拖尾，笔尖有光点 |
| A2 | 拖尾停止移动 1 秒 | 轨迹自动淡尽，画布清空 |
| A3 | 绕椭圆一圈后停 0.4s | 锁定，浮窗进入草稿态 |
| A4 | 绕圈不足 330° | 不锁定 |
| A5 | 圈住按钮，右侧紧邻另一个按钮 | 只选中 1 个，显示正确 `文件:行:列` |
| A6 | 圈住两张卡片 | 选中 2 个，编号按视觉顺序 |
| A7 | 圈住表格 3 行 | 选中的是 3 个 `tr`，不是若干 `td` |
| A8 | 圈住 10 行表格 | 最多 6 个 |
| A9 | 全程 | 无 `mousedown`、无 `click`、页面无任何副作用 |
| A10 | 锁定后 | `data-ait-state` 含 `sel=n`，可核对 |
| A11 | 慢速绕圈（40 点、耗时 4s） | 仍能锁定，起点不被时间窗裁掉 |
| A12 | 圈整片压在浮窗上 | 作废并提示，不选页面元素 |

实测（`scripts/verify-loop.mjs`，真实扩展 + CDP 纯移动）：16/16 通过。数据点：拖尾 521 像素 / 153 级不透明度；整圈 40 点、350°、首尾距 0.04；圈单按钮选中 1 个；圈两行表格选中 2 个 `tr`（`LoginHistory.vue:52`）；全程 click 0 次。
